# 📚 E-Library Management System

> A robust, full-stack enterprise web application designed to streamline library operations, digital catalog browsing, and secure user book-borrowing workflows.

---

## 🛠️ Tech Stack & Architecture
- **Backend:** Java Spring Boot, Spring Security, Thymeleaf
- **Database & Persistence:** MySQL
- **Development & Testing:** IntelliJ IDEA, Postman
